ZeroCool AI 교육수료관리 v14.6

[디자인 개선]
- 전체 창 크기 및 좌우 패널 비율을 대시보드형으로 확대
- 네이비 헤더, 밝은 카드형 배경, 버튼 간격과 글꼴 크기 정리
- 상태 범위와 조회 항목을 색상형 선택 버튼으로 유지
- 상태 범위/조회 항목 각각 전체 선택 기능 유지
- 선택 조건 조회, 오늘 업무, 조회 결과 보기, 기타 기능의 4단 구조로 정리
- 불필요한 별도 미수료 재조회 버튼은 기타 기능으로 이동
- 진행률 바와 로그 탭 디자인 개선

[조회 기능]
- 수료조회 또는 예약조회 한 가지만 선택 가능
- 수료조회와 예약조회 모두 선택 가능
- 둘 다 선택 시 수료조회 후 예약조회 순서로 진행
- 2026년 실제 수료 또는 유효한 2026년 예약만 교육시청일 변경
- 과거 미수료 일정은 기존 교육시청일 유지
- 서울 예약조회 차량번호 미사용
