ZeroCool AI 보수교육 관리 v15.0

[핵심 변경]
- 보수교육 수료·예약 조회 중심으로 화면과 문구 정리
- 서울 예약조회 주소를 https://edu.tredu.kr/ 로 변경
- main 프레임 우선 탐색 후 '교육 예약확인 및 변경' 진입
- 성명/주민번호 입력, 약관 동의, 실명인증, 레이어 팝업 닫기 후 예약목록 확인
- 수료조회와 예약조회를 서로 다른 프로세스로 순차 실행
- 예약조회 오류가 수료여부·수료일·구분을 변경하지 않도록 보호
- 수료조회에서 예약일 또는 교육시청일을 갱신하지 않도록 분리
- 실제 확인된 당해연도 미래 예약만 교육시청일 변경
- 과거 예약, 예약없음, 조회오류는 기존 교육시청일 유지
- 오늘 업무 및 AI 추천순서 노출 제거, 메인 UI 단순화

[주의]
- 서울 사이트의 실제 화면 구조가 변경되면 debug 폴더의 HTML/PNG를 기준으로 보완할 수 있습니다.
